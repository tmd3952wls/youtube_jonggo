# 참고 쇼츠 복제 대본 예시 — 역할 지도 방식 (참고 쇼츠 → 새 주제)

## Brief (사용자 요청)
- 참고: https://www.youtube.com/shorts/qk93I4Mi0EM ('사서알려줌' — 루스벨트 대통령 영상 하나에 1.2억원?!)
- 원본 쇼츠의 틀을 그대로 복제하고 **주제만** 바꾼다. 생성 AI(힉스필드 등) 없이.
- 대본도 Hypit 스킬 방식(참고 영상의 사건별 '역할'을 지키고 내용만 새로 입힘)으로 쓴다.
- 음성은 채널 고정값: 캡컷 활기찬 바리톤 1.1배속. 원화는 붙여 쓰기.
- 결과: 대본 방식만 채택. Hypit의 화면 조립은 쓰지 않기로 함.

## Analysis (참고 영상이 왜 먹히는가)
- 화면: 검은 바탕 / 위 제목 2줄 고정(노랑 + 빨강, 물건 + 금액 물음) / 가운데 1080x1040 영상 띠 / 자막은 영상 한가운데 아래쪽에 작게, 핵심어만 형광색.
- 소리: 해설은 **4번만** 짧게(훅, 장면 넘김, 가격 직후, 결말). 나머지 45초는 원본 대사 + 번역 자막. 빈틈 없음, 배경음 계속.
- 이야기: "엄청난 값이라는 물건" → 정체 → 어떻게 구했나 → 대단한 발견 → **직접 확인하는 장면(영상 재생)** → 가격 → 릭은 다르게 생각 → 빈손 → **끝에 김 빠지는 실제 시세 한 줄**.
- 흥정 주고받기가 거의 없다. 긴장은 "확인 장면"과 "마지막 반전 숫자"가 만든다.

## Treatment (새 주제: 지미 헨드릭스 1963 펜더 스트라토캐스터, 시즌 9 'Purple Haze')
같은 역할에 새 내용을 입힌다. 방송에 나온 말과 조사된 사실만 쓴다.
| 역할 | 새 영상 |
|---|---|
| 훅 | [해설] 낡은 기타 한 대를 들고 전당포에 온 남자 / 무려 10억원이 넘는 엄청난 기타라는데 |
| 정체 + 놀람 | 1963년산 펜더 기타인데 / 지미 헨드릭스가 쳤어요 / 와, 그건 대박인데 |
| 구한 사연 | 어디서 구했어요? / 녹음실 엔지니어 거였어요 / 앨범 녹음 끝나고 선물받은 거죠 |
| 가치 띄우기 → 확인 예고 | 이건 성배예요 / 진짜인지는 제 친구가 알 거예요 |
| 장면 넘김 | [해설] 그렇게 전문가까지 불러 직접 소리를 들어보는데 |
| 직접 확인 + 판정 | 의심할 여지 없이 진짜 헨드릭스 기타예요 / 꽂고 한번 질러 보죠 |
| 가격 공개 | 그래서 얼마 원하세요? / 10억5천만원이요 |
| 손님 근거 → 반전 예고 | [해설] 전문가도 14억원까지 본다는 손님 / 그래도 릭의 생각은 달랐는데 |
| 사장의 거절 논리 | 6억3천만원 드릴게요 / 위험은 제가 다 지잖아요 / 그 값엔 못 팔아요 |
| 결말 + 김 빠지는 시세 | [해설] 그렇게 빈손으로 돌아갔지만 / 이 기타의 2007년 경매 낙찰가는 / 고작 1억1천만원이었다고…. |

- 다른 점(사실에 맞춤): 참고 영상의 릭은 값을 안 불렀지만, 이 편의 릭은 실제로 6억3천만원부터 불렀으므로 한 번은 보여 준다.
- 참고 영상의 '*영상 재생*' 장면은 기타 연주가 딱 맞는 짝이지만, 현재 편집 도구가 대사 없는 구간의 원본 소리를 못 살려서 연주 화면은 해설 밑그림으로만 쓴다.
- 결말 숫자: 2007년 6월 페임 뷰로 경매 6만 파운드 (출처: Paul Fraser Collectibles).
